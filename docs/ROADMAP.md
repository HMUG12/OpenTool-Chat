# OpenClass-Box 产品规划（v1）

> 定位源自实际场景：**课堂一体机的「离线急救箱」**——老师一键自救、学生电教日常维护、
> 专业人员深度排障。不做通用工具箱，聚焦教室场景的真实痛点。

---

## 一、产品定位

**一句话**：课堂一体机的离线急救箱。

| 维度 | 说明 |
|---|---|
| 部署环境 | 教室一体机（Windows 10/11），网络受限或不可控，无人值守 |
| 使用者 | 非专业用户占多数（老师），操作时间窗口极短（上课前几分钟） |
| 核心价值 | 离线可用、免依赖（内置运行时，目标机无需装任何东西）、一键化 |
| 差异化 | 通用工具箱在「课堂急救」这个场景里做不深：我们要的是**结论**，不是工具集 |

## 二、三类用户 × 功能矩阵

### ① 老师 —— 一键自救（最高优先）
| 场景 | 功能 |
|---|---|
| 上课前发现「没声音 / 投影不出 / 网断了 / 卡」 | **一键体检**：声音、显示（投影/分辨率）、网络、声音设备、磁盘、温度，逐项给「正常 / 异常」结论 |
| 需要立刻恢复 | **一键修复**：重启音频服务、重置网络、重启显卡驱动、清理临时文件、恢复投影扩展模式 |
| 看不懂专业信息 | 大按钮 + 大白话结论 + 「修好了 / 请报修」二分输出 |

### ② 学生电教 —— 日常维护
| 场景 | 功能 |
|---|---|
| 每周维护 | 一键清理（垃圾/缓存/浏览器残留）、磁盘空间报告 |
| 装软件 | 离线软件目录批量安装（预制安装包） |
| 出问题要报修 | 一键导出**硬件与系统信息报告**（含截图，供维修人员） |
| 系统还原 | 创建/回滚还原点入口（危险操作二次确认） |

### ③ 专业人员 —— 深度排障
| 场景 | 功能 |
|---|---|
| 疑难故障 | 日志一键采集打包（系统日志/应用日志/驱动状态） |
| 网络问题 | 网络诊断组合：ping / traceroute / DNS 解析 / 网卡状态 / 占用端口 |
| 启动异常 | 进程 / 服务 / 启动项查看与管理 |
| 硬件怀疑 | 硬件详情（已有）+ 温度/磁盘健康（SMART） |

## 四、迭代路线（建议）

### P0 —— 「一键急救」（把它做成产品的脸）
1. **一键体检**页：大按钮 → 逐项检测（声音/显示/网络/磁盘/温度）→ 结论清单
2. **一键修复**：常见课堂故障的修复动作（网络重置、音频服务重启、临时文件清理、投影模式修复）
3. 离线可用：所有检测与修复**不依赖外网**

### P1 —— 「维护」
4. 一键清理 + 磁盘报告
5. 系统信息/报修报告导出
6. 离线软件目录批量安装
7. 还原点入口

### P2 —— 「深度」
8. 日志采集打包
9. 网络诊断套件
10. 进程/服务/启动项管理、SMART 磁盘健康

## 五、产品原则（写进开发规范）

1. **离线优先**：检测与修复不依赖外网；联网功能（更新检测/音乐）必须可降级
2. **免依赖**：内嵌运行时；目标机无需安装任何前置组件
3. **一键化 + 结论化**：面向老师的功能只暴露「一个按钮 + 一句结论」
4. **危险操作可回滚**：清理/重置类操作先备份、二次确认、可恢复
5. **不碰红线**：不内置任何绕过授权/破解类功能
